# BZZ3003: unwrap of a non-optional

The `!` operator unwraps an optional and fails at run time if it is null. On a
value that cannot be null it does nothing:

```buzz
final n: int = 3;
final m = n!;          // BZZ3003
```

```text
[BZZ3003] buzz: line 2:11: warning: force-unwrap `!` on "n", which is not optional
  see: .../BZZ3003.md
```

Like [BZZ3001](BZZ3001.md) this is a **warning**: it never fails `Exec` or
`Compile`, and the program still runs.

## Resolution

Remove the `!`, or declare the value optional if it can be null:

```buzz
final n: int? = null;
final m = n!;
```

## When it does not fire

The checker fires only when the declaration proves the value is not optional: a
scalar literal, or a name declared with a type that has no `?`. An optional, an
`any` value, and a name whose type was inferred from a call stay silent, since
an inferred binding may be an optional the checker cannot see.
