# BZZ1009: namespace not imported

A name was qualified with a namespace (`magus\Context`, `fs\read`,
`demo\Thing{}`) that no import in this module binds. Each module names a
namespace only through its own imports: another module in the program having
imported it does not make it visible here. Upstream Buzz refuses the same
source.

```text
[BZZ1009] buzz: line 1:8: undefined type "magus\Context": no import binds magus in this module; add `import "magus";`
  see: .../BZZ1009.md
```

When the host registered a module that binds the namespace, the message names
the import line to add. Otherwise it stops at the namespace, since the module
path is not knowable from the name alone.

## Resolution

Import the module that binds the namespace at the top of this file:

```buzz
import "magus";

export fun ci(ctx: magus\Context) > void !> any {}
```

If the namespace is misspelled, fix the spelling instead. A namespace this
module does import but that declares no such type is BZZ1002, not this code.
