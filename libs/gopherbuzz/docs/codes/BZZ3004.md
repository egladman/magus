# BZZ3004: discarded value

A statement made of a single expression throws its value away. When that value
is not `void`, the result was probably meant to be used:

```buzz
fun double(n: int) > int {
    return n * 2;
}

double(3);             // BZZ3004
```

```text
[BZZ3004] buzz: line 5:1: warning: discarded value of type `int`
  see: .../BZZ3004.md
```

Like [BZZ3001](BZZ3001.md) this is a **warning**: it never fails `Exec` or
`Compile`, and the program still runs. Upstream Buzz reports the same case as
`Discarded value of type`.

## Resolution

Use the value, or discard it on purpose by assigning it to `_`:

```buzz
final six = double(3);
_ = double(3);
```

## When it does not fire

An assignment, a call returning `void`, and an expression whose type is `null`
stay silent, as upstream. So does an expression whose type the checker could not
track, such as the result of an FFI call.
