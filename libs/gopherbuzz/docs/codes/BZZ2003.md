# BZZ2003: native FFI disabled

The embedding host disabled `zdef`, so this script cannot load a native function.

## Resolution

Remove the `zdef` call. If the script needs native FFI, run it through the regular
`magus buzz` CLI instead of an embedding that disables FFI.
