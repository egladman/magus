# BZZ1004: argument error

A function call did not match the function's parameters, or an object literal
did not match its object's fields. This covers the whole family of call-shape
mistakes:

- wrong argument count,
- a missing required argument,
- an unknown argument name,
- the same argument given twice,
- a positional argument after a named one.

```text
[BZZ1004] buzz: line 7:1: wrong argument count: got 1, want 2
  see: .../BZZ1004.md
```

An object literal `Point{ x = 1 }` is the same shape, with fields as the named
arguments. It fails when it names a field the object does not declare, or
leaves out a field that has no default:

```text
[BZZ1004] buzz: line 6:12: object Run has no field "id"
[BZZ1004] buzz: line 6:12: Property `sha` was not initialized and has no default value
```

## Resolution

Check the function's signature and match it: pass every required argument,
spell named arguments as the parameter names, and put all positional arguments
before any named argument.

For an object literal, set only the fields the object declares, and every field
without a default. A qualified literal `ns\Run{...}` names the `Run` that `ns`
exports, not another module's type of the same name.
