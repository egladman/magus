# BZZ3001: unused import

An `import` bound a namespace name - its alias, or the path's basename with no
alias - that nothing in the file ever referenced: not `name\member`,
`name.member`, a bare use of `name` as a value, nor `name\Type{...}` /
`name\Type` in a type position.

```text
[BZZ3001] buzz: line 3:1: warning: import "helpers/math" is never used
  see: .../BZZ3001.md
```

Unlike every other BZZ code, this one is a **warning**: it never fails
`Exec` or `Compile`, and the program still runs. It is reported by
`Session.Diagnostics` for editor tooling, matching upstream Buzz's own
`unused_import` warning.

A flat import (`import "m" as _;`) or a selective import
(`import a, b from "m";`) is never flagged - neither binds a single
namespace name to check. An interactive REPL session never sees it either:
each line is parsed on its own, so an import "unused so far" may simply be
used by a line typed later.

## Resolution

Reference the import, or delete it. If the import is aliased and the alias is
what goes unused, either use the alias or drop the `as` clause.
