# BZZ1010: write to an immutable map or object

Maps and objects are immutable unless built with `mut`. Assigning a key of an
immutable map, or a field of an immutable object, fails when the program runs.
The checker reports it earlier whenever it can see how the value was built.

```buzz
final m = {"a": 1};
m["b"] = 2;            // BZZ1010

final p = Point{ x = 1 };
p.x = 2;               // BZZ1010
```

```text
[BZZ1010] buzz: line 2:1: cannot mutate immutable map "m": declare it with `mut` to write a key
  see: .../BZZ1010.md
```

The check fires only when the immutability is known: a map whose type is not
`mut`, or an object bound directly from a plain literal. A value the checker
cannot trace, such as an `any` parameter, stays silent and fails at run time.

## Resolution

Build the value with `mut`:

```buzz
final m = mut {"a": 1};
m["b"] = 2;

final p = mut Point{ x = 1 };
p.x = 2;
```

A parameter that is written through takes a `mut` type, such as
`m: mut {str: int}`.
