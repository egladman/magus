# libs/marks

Marks drawn from geometry in Buzz, flat and two-color like buzzed's pull-tab icon.

```sh
magus run generate libs/marks    # every mark into gen/
```

`safetyscissors.buzz` draws the `libs/safetyscissors` mark: kids' safety scissors in
charcoal on caution yellow, half open and leaning, each blade the hull of a round blunt
nose and a hub shared on the rivet. The pair is balanced on the optical center, then
nudged down and right where the eye reads its weight.
