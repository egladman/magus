# MGS9013: console not built

The server answered `400 bad request` to a share request because it serves no
built console, so a device opening the share link would load nothing.

```text
[MGS9013] no built console is served, so there is nothing to share; set
MAGUS_CONSOLE_DIR to a directory holding a built console's index.html, then
restart the server
  see: .../MGS9013.md
```

## Why

A share opens a LAN listener that serves the console app to another device.
The server serves only the build `MAGUS_CONSOLE_DIR` names, and needs an
`index.html` there. It never falls back to the workspace's own
`<root>/console/gen`: a cloned repository writes that directory, and the page
it holds would read the token from the share link. Opening a listener with
nothing behind it would hand the other device a 404 in place of the app.

## Resolution

Point `MAGUS_CONSOLE_DIR` at a directory holding a built console, then start
the share again. To serve a console you built in this repository, run
`magus run build console` and set `MAGUS_CONSOLE_DIR` to its `console/gen`.
The server reads the variable when it starts, so restart it after setting it:
`magus server stop`, then `magus server start`.
