# MGS9014: share could not open

The daemon did not open a share. Either the request asked for a lifetime it
refuses, answered `400 bad request`, or it could not open the LAN listener the
other device connects to, answered `503 service unavailable`.

```text
[MGS9014] auth: a share link lives between 1 minute and 24 hours: asked for 720h0m0s
  see: .../MGS9014.md
```

A share link is a bearer credential served over plaintext HTTP and bound to a
device by its address alone, so it lives a day at most. A request outside the
range is refused rather than shortened. Pick a shorter lifetime, and share again
tomorrow for a display that stays up.

```text
[MGS9014] share: no up, non-loopback, private-range IPv4 interface found;
connect to a LAN or Wi-Fi network and try again
  see: .../MGS9014.md
```

## Why

A share serves the console on this machine's private LAN address, never on a
public one. With no private-range IPv4 interface up there is no address a
nearby device could reach, and a listener that cannot bind has nothing to
serve on.

## Resolution

Connect to a LAN or Wi-Fi network and start the share again. If one is
connected, the message names the address the listener could not bind; free
that port or retry once whatever holds it exits.
