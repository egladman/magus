# MGS9006: token not found

`magus config mcp connector revoke` or `magus config console token revoke`
named a token, by name or id, that its pool does not contain.

```text
[MGS9006] magus config mcp connector revoke: no connector matches "ci"
  see: .../MGS9006.md
```

## Why

Revoke resolves what you named against the store as it is now: an exact name,
then an exact id, then a unique id prefix. Each command sees only its own pool,
so a console token is never revoked by the connector command and the reverse.
Nothing matched: the name or id is wrong, it was already revoked, or it is in
the other pool (the message says so, and names the command that revokes it).

## Resolution

List what is there and revoke by an exact name or id from the list:

```sh
magus config mcp connector ls
magus config mcp connector revoke <name-or-id>
```

An id prefix works if it is unambiguous; if it matches more than one token,
magus asks you to disambiguate rather than guess.

## What this is NOT

- **Not the operator token.** It is not in the store and is never a revoke
  target here; rotate it with `magus config token generate --force`.
