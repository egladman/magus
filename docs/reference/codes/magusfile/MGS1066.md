# MGS1066: a hole is not a name, a conversion and a spec

```text
{{hole}}
package {{pkg.name:ident}}
```

```text
x.go.tmpl:2:11: [MGS1066] hole "pkg.name:ident" reads a dotted or indexed name: compute one name in Buzz
```

## Why

A hole reads one name from `values`, with an optional conversion and an optional
encoding: `{{name!s:raw}}`. A path, an index, a call or a debug form would be logic
in template text, and a template file cannot see the script's scope to run it.

## Resolution

Compute the value in Buzz and pass it under one name: `values: {"pkgName":
pkg.name}`, then write `{{pkgName:ident}}`. A name is ASCII letters, digits and
`_`, not starting with a digit.
