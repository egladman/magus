# MGS1071: a hole names no encoding

```text
{{hole}}
package {{pkg}}
```

```text
x.go.tmpl:2:9: [MGS1071] pkg names no encoding; write pkg:ident, :string, :block or :raw
```

## Why

No default is right in every position a hole can take: a name, a quoted literal and
verbatim text each need a different encoding. A raw default would let a keyword, a
space or a quote into code unchecked, which is the failure emit exists to stop.

## Resolution

Name the encoding: `ident` for a name, `string` for a string literal, `block` for a
nested template, `raw` for text copied as it is. A spell may declare more for its
language; MGS1072 lists them.
