# MGS1073: a value's kind does not fit its encoding

```text
x.go.tmpl:3:12: [MGS1073] port is an int and :raw takes a str; write {{port!s:raw}}
```

## Why

Every encoding but `block` takes a `str`, and `block` takes a template. A scalar
written into a str hole without saying so, or a template printed as text, would
produce bytes nobody chose.

## Resolution

Write `!s` before the encoding to write an int, a double or a bool in its string
form. Wrap a `str` meant for a block hole with `emit\text`. Pass a template to a
`:block` hole, never to a str hole.
