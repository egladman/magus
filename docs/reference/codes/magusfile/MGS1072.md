# MGS1072: the output's language has no such encoding

```text
x.yaml.tmpl:4:7: [MGS1072] no spell declares a language for ".yaml" (config/x.yaml), so :string has no meaning; block and raw exist. add the extension to a spell's mgs_getLanguage, or encode in Buzz and name raw (writing config/x.yaml)
```

## Why

The output path's extension picks the language, and the language's spell declares
its encodings as data in `mgs_getLanguage`. `block` and `raw` belong to the engine
and exist for every path. Nothing falls back to `raw`: a value written raw where a
string literal was meant can break out of its quotes.

A run that carries no spell languages at all is refused under this code too, since
no encoding could be resolved in it. `magus buzz`, a target and the MCP Buzz tool
each carry the workspace's languages.

## Resolution

Use an encoding the message lists, or add the encoding to the spell that declares
the language. To write a value no encoding covers, encode it in Buzz and name
`raw`.
