# MGS1070: a value is null

```text
x.go.tmpl:5:3: [MGS1070] value "doc" is null: compute it before load, or drop the hole
```

## Why

A hole bound to null would render as nothing or as the word `null`, and neither is
a choice anyone made. The choice of what an optional part holds belongs in Buzz.

## Resolution

Compute the value before `emit\load`. For an optional part, write the hole as
`:block` on its own line and pass `emit\text("")` when there is nothing: an empty
block removes its line.
