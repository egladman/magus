# MGS1064: a template's first line is not its delimiter

```text
package {{pkg:ident}}
```

```text
x.go.tmpl:1:1: [MGS1064] line 1 must show the delimiter as a hole: {{hole}}
```

## Why

A template file declares its hole delimiter on line 1 by showing it: N opening
braces, the word `hole`, N closing braces, with N from 1 to 8 and nothing else on
the line. Every brace run shorter than N in the rest of the file is target text, so
the target's own braces never need escaping. A file with no such line would have
its delimiter guessed, and a wrong guess turns target braces into holes or holes
into text.

## Resolution

Add a first line holding the hole form with the brace count the file uses, for
example `{{hole}}`. Pick a count longer than any brace run the target text holds:
`{{{hole}}}` for a GitHub workflow that writes `${{ github.sha }}`.
