# MGS1065: a brace run opens or closes no hole

```text
{{hole}}
var m = map[string]struct{}{{{key:string}}: {}}
```

```text
x.go.tmpl:2:28: [MGS1065] 5 opening braces in a row: text holds at most 1 with delimiter 2; raise the count on line 1
```

## Why

With delimiter N, a run of fewer than N braces is text and the last N braces of a
longer run open a hole. A run of 2N or more cannot be read either way without a
guess, so it is refused. A group written with another count whose name is a key of
`values` is refused too: it reads as text, so the value would never be written.

## Resolution

Raise the count on line 1 until no run in the target text reaches it, and write
every hole with the new count. When the message names a value written with the
wrong count, retype that hole with the file's delimiter.
