# MGS1078: a plan writes one path twice

```text
internal/a/a_test.go: is written twice (files 3 and 7): keep one file per path [MGS1078]
```

## Why

Two files for one path would leave the last one standing, and nothing would say the
first was lost. Paths are compared after resolving against the working directory,
so `a.go` and `./a.go` are the same path.

## Resolution

Keep one file per path. When two parts belong in one file, join their templates
with `emit\join` and plan one file.
