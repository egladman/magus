# MGS1058: something other than a symlink under .magus/workspaces

```text
[MGS1058] /home/me/Repos/buzzed/.magus/workspaces/magus is not a symlink, so the load
cannot point it at /home/me/Repos/magus; magus deletes nothing it did not make, so
move it away
```

## Why

The load writes and removes only symlinks directly under `.magus/workspaces/`. A
directory there may hold someone's work, and nothing is ever deleted through a link.

## Resolution

Move the file or directory away, then run any magus command; the load makes the
symlink.
