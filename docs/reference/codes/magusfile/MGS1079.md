# MGS1079: an output has no final newline

```text
a.go: does not end in a line feed: end x.go.tmpl with a newline [MGS1079]
```

## Why

A file with no final newline is changed by the first editor or formatter that
touches it, so the first diff after the write would be churn. The template's final
newline is the output's final newline.

## Resolution

End the template file with a newline. For a template built in Buzz, end its last
static text with `\n`.
