# MGS1074: the encoding refuses the value

```text
x.go.tmpl:12:6: [MGS1074] fn: "range" is reserved, so :ident refuses it
```

## Why

An encoding promises that what it writes is one token of the kind its name says. A
keyword passed as an identifier, a name with a space in it or a control character a
string literal has no escape for would each become code that means something else.
`raw` refuses an empty value, which reads the same as a forgotten one, and a line
feed, which `block` handles with indentation.

## Resolution

Pass a value the encoding accepts. `ident` checks the value alone, so build a joined
name such as `Test` + `type` whole in Buzz and pass it as one value. For nothing in
a raw position, pass `emit\text("")` to a `:block` hole.
