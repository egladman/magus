# MGS1069: a value is read by no hole

```text
x.go.tmpl: [MGS1069] value "pkgName" is read by no hole: remove it from values
```

## Why

A key no hole reads is usually a misspelled hole name, and ignoring it would let
the hole it was meant for go unnoticed. `values` must name every hole and nothing
else.

## Resolution

Remove the key from `values`, or rename it to the hole it was meant for. To share
values between two templates, build one map per template.
