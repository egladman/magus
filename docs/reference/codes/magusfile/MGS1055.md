# MGS1055: knowledge.workspaces in a repository

```text
[MGS1055] knowledge.workspaces is personal: move it from magus.yaml:12 to
$XDG_CONFIG_HOME/magus/magus.yaml
```

## Why

Connecting two workspaces is a development aid on one machine. Committed, the list
would connect every clone and every CI run to checkouts that exist only on the machine
that wrote it.

## Resolution

Move the entries to `$XDG_CONFIG_HOME/magus/magus.yaml`, the user config:

```yaml
knowledge:
  workspaces:
    - name: magus
      path: ~/Repos/magus
    - name: buzzed
      path: ~/Repos/buzzed
```
