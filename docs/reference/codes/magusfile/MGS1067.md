# MGS1067: a template holds bytes it may not

```text
x.go.tmpl:3:22: [MGS1067] carriage return: the template has LF line endings only
```

## Why

Output is the template's text after line 1, byte for byte. A CRLF or BOM template
would make every output it writes differ from the files beside it, and the
difference would be blamed on the output. The refusal names the template and the
line, once per kind of bad byte per line.

## Resolution

Save the template as UTF-8 without a byte-order mark and with LF line endings.
