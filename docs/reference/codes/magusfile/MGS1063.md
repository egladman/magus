# MGS1063: an edit plan was refused

```buzz
import "splice";

final plan = splice\plan([
    splice\replace("missing.go", old: "x", new: "y"),
    splice\replace("a.go", old: "f()", new: "g()"),
]);
final applied = splice\apply(plan);
```

```text
[MGS1063] missing.go: no such file; a new file is a creation
a.go: old occurs 2 times, at a.go:3:12, a.go:3:17: pass the line's own text, or
replace every occurrence (`replaceAll`, or an `old all` block)
```

## Why

`splice\apply` writes every file of a plan or none of them. It plans the changes
again before it writes, and it refuses when that plan carries a refusal or when
its digest differs from the one `splice\plan` returned. A digest that moved means a
file changed after the plan was read, and writing anyway would replace bytes
nobody reviewed.

The refusal is the `error` of the Result `splice\apply` returns, not a raise, so a
script reads it as data. A failed write carries the I/O error's message and no
code.

## Resolution

Fix each refusal the message names: every one says what to pass instead. Then
call `splice\plan` again and apply the new plan. A plan whose every change the tree
already holds applies with nothing to do, so planning again after a partial
manual fix is safe.
