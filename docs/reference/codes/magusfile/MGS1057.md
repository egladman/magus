# MGS1057: .magus/workspaces is not ignored

A listed workspace gets one symlink per other entry under `.magus/workspaces/`. Before it
makes any, the load asks the workspace's VCS whether that directory is ignored:

```text
[MGS1057] git does not ignore .magus/workspaces, so the workspaces
knowledge.workspaces connects could be committed; .magus/ must be ignored: add it to
the ignore file
```

## Why

Nothing is committed to connect two workspaces. A symlink to another checkout,
committed, would point every clone at a path on one machine.

## Resolution

Add `.magus/` to the repository's ignore file, `.gitignore` for git.
