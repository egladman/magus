# MGS1077: a template's strings and holes do not pair

```text
a template built in Buzz: [MGS1077] a template with 2 holes holds 3 strings; this one holds 2
```

## Why

A template is static strings around holes: one string before each hole and one
after the last. `emit\load`, `emit\text`, `emit\hole` and `emit\join` always build
that shape. A `Template` object written field by field can break it, and the
renderer cannot tell which text goes where.

## Resolution

Build the template with `emit\text`, `emit\hole` and `emit\join` instead of by
hand, or give `strings` one more item than `interpolations`.
