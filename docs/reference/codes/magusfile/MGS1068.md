# MGS1068: a hole has no value

```buzz
import "emit";

final t = emit\load("x.go.tmpl", values: {"pkgName": "price"});
```

```text
x.go.tmpl:2:9: [MGS1068] hole "pkg" has no value: add "pkg" to values
```

## Why

A misspelled hole or key would otherwise render as nothing, and the file would be
wrong with no error. `values` must name every hole.

## Resolution

Add the hole's name to `values`, or rename the hole to the key you meant.
