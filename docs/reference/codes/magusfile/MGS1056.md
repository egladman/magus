# MGS1056: a knowledge.workspaces entry magus cannot read

Every entry is `{name, path}`. The name is `[a-z0-9-]+` and unique in the list; it is the
label every path and row uses, `.magus/workspaces/<name>`. The path is absolute or starts
with `~`.

```text
[MGS1056] line 3: knowledge.workspaces entry "/home/me/Repos/magus" is a bare value;
write it as {name: <name>, path: /home/me/Repos/magus}
```

## Why

The list once held bare roots, and their basename named them, so two checkouts with one
directory name merged. A name of the person's choosing cannot collide, and a relative
path would mean a different directory from each working directory.

## Resolution

Write the entry the message names:

```yaml
knowledge:
  workspaces:
    - name: magus
      path: ~/Repos/magus
```
