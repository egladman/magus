# MGS1075: a conversion other than !s

```text
x.go.tmpl:4:3: [MGS1075] !r is not supported: Buzz has no repr or ascii; write !s or drop the conversion
```

## Why

A template accepts PEP 750's three conversions, and a present conversion is
respected, never dropped. Buzz has a string form of a value but no `repr` or
`ascii`, so `!r` and `!a` cannot be respected and are refused rather than ignored.

## Resolution

Write `!s`, or drop the conversion and pass a `str`.
