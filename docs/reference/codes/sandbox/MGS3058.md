# MGS3058: a job store line this magus does not read

`magus job fork`, `magus ls jobs` and every other command that reads the job store
refused because a line carries a group or version this magus neither reads nor
migrates:

```text
[MGS3058] job: ~/.local/state/magus/jobs/.../jobs.jsonl:2 is example.jobs/v1,
  which this magus (safetyscissors.job/v1alpha1) does not read and no migration
  reaches: move it aside and fork the job again, or start a fresh session
```

Nothing was read or written.

## Why

A job store migrates forward once, under the lock, from the migrations this magus
knows: the `batch.magus/v1alpha1` rows an older magus wrote become
`safetyscissors.job/v1alpha1`. A line in any other group, or an older version no
migration converts, holds rows whose meaning this magus cannot tell, so it refuses
the store rather than guess. A newer version of the job group is
[MGS3047](MGS3047.md) instead, and an update reads it.

## What to do

Move the named store aside and fork the job again, or start a fresh session, which
opens an empty store.
