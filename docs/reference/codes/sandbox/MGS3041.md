# MGS3041: a job checkpoint this checkout cannot place

`magus job fork`, `magus job apply` and `magus\job.put` refused a job record
whose checkpoint this checkout cannot start from:

```text
[MGS3041] checkpoint "abc123" is not HEAD or an ancestor of it in this checkout:
  fork the job where that revision is checked out, or name `magus vcs checkpoint -o name`
```

Nothing was written to the job store.

## What fires it

- A checkpoint revision this checkout's history does not hold below HEAD.
- A checkpoint digest that does not match the working state it names.

## What to do

Fork the job in a checkout at that checkpoint, or replace the checkpoint with
the one this checkout prints:

```sh
magus vcs checkpoint -o name
```
