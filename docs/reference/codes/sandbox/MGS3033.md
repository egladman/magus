# MGS3033: buzz transform failed

The message following the code names the failed part of the request or includes
the Buzz compiler/runtime diagnostic.

## What to do

- Supply exactly one of `script` or `path`, and pass JSON data through `input`.
- Define `transform(input: any, args: [str])` and return a JSON-encodable value.
- Fix any nested `BZZ####` compiler or import diagnostic first.
- File imports, native FFI, and workspace-changing host modules are not offered
  by this MCP transform. Workspace queries and actions go through the `client`
  tool. Use the regular `magus buzz` CLI for scripts that need the rest of the host.
- If the worker reports an invalid response, report it as a Magus bug with the
  diagnostic and server version.
