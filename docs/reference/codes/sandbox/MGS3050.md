# MGS3050: a store line that cannot be decoded

A line in a magus store did not decode as a record:

```text
[warn] MGS3050 history: skipped ~/.local/state/magus/history/v1.json:812 because
  it is not a run-history record (unexpected end of JSON input); the rest of the store is read
  fix: delete that line, or leave it; the next compaction drops it
```

A store is JSON Lines: one record per line. This line is not valid JSON, is cut
short, or has the wrong shape for the store. A write cut off by a crash or a
full disk leaves one, and so does an edit by hand.

A corrupt line is not a newer one. A record a newer magus wrote decodes, names
what it requires, and is kept for that magus ([MGS3047](MGS3047.md)). This line
holds nothing any magus can read.

## What still works

- Every other line in the store is read, so one bad line costs one record.
- The command goes on, and says once which lines it skipped.

## What to do

Open the store at the line named and delete it, or leave it: the store's next
compaction rewrites only the records it read. If lines go bad again, look for
what writes the store besides magus, or for a disk that fills.
