# MGS2012: sandbox required

`sandbox.required` (or `MAGUS_SANDBOX_REQUIRED=1`) is set, and the kernel is not
enforcing the sandbox. magus stops before running anything.

```text
[MGS2012] sandbox.required is set for /tmp/mergequeue-apply-1/candidate-7/checkout,
and the kernel cannot enforce it: sandbox: kernel sandbox unsupported on this host;
run it on Linux 5.13 or newer with landlock enabled (/sys/kernel/security/landlock)
```

## Why

Without kernel landlock the sandbox falls back to interpreter-level checks
([MGS2005](MGS2005.md)). Those confine what a spell does through magus's own
bindings, and nothing a subprocess does: a tool writing through a symlink, or
any native code, is out of their reach. That fallback is a fair trade for a
developer's own build. It is not one for code nobody trusts running in a job
that holds a credential, so a caller that needs the kernel's guarantee says so
and magus refuses rather than degrade.

The merge queue is that caller. `magus queue apply` runs main's regeneration in
the job holding the write credential, on a checkout carrying a change's files,
and sets `MAGUS_SANDBOX_ENABLED=1` and `MAGUS_SANDBOX_REQUIRED=1` for it. Before
merging anything it checks the host itself and refuses with this code, so a
host that cannot sandbox stops the run instead of kicking every change back.

It fires in three ways:

- landlock is unavailable on this kernel (macOS, Windows, or Linux older than
  5.13 or without the LSM);
- `sandbox.required` is set and `sandbox.enabled` is not;
- an earlier apply in the same process, one that did not require the sandbox,
  already fell back to interpreter-level checks.

## Resolution

- Run on Linux 5.13 or newer with landlock enabled; check that
  `/sys/kernel/security/landlock` exists. GitHub's hosted Ubuntu runners have it.
- Set `sandbox.enabled` together with `sandbox.required`.
- For `magus queue apply`, run apply without `--regenerate` on a host that
  cannot sandbox: a change needing regeneration then goes back to its author,
  who regenerates and pushes.
