# MGS3051: a job store this magus cannot read or write

`magus job fork`, `magus job apply`, `magus ls jobs` and every other command that
touches the job store refused because the store's header names a feature this
magus does not implement:

```text
[MGS3051] ~/.local/state/magus/jobs/.../jobs.jsonl requires "jobs-v2",
  which this magus (schema 23) lacks, update magus
```

Nothing was written to the job store.

## Why

Every checkout of a repository shares one job store. A newer magus can write a
store whose rows an older one would misread, so it records the features a reader
must implement in the store's header, and an older magus refuses it rather than
guess.

The refusal judges the store's schema, not the commit that wrote it. A magus built
from an older commit, or from a modified tree, reads and writes a store freely as
long as it implements every feature the header requires.

## What to do

Run the command with a `./magus` built from a commit that implements the feature
the message names, such as the current base.
