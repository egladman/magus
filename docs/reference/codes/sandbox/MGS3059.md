# MGS3059: a path held by a job nobody is working

`magus describe job` lists a path another live job holds, and that job's row
has not been touched within `jobs.stale_after`:

```text
[MGS3059] hack/lint/run.buzz is held by job 887-lint-run, untouched for 5h12m (jobs.stale_after
is 1h); the root or a person checks it: `magus job prune --dry-run --all 887-lint-run`
```

A holder touched within the window gets the plain reason instead, "owned by
live lease X: coordinate, never work around", and no code.

## Why the path stays refused

A quiet row does not prove its holder left. A long check, or a person away from
the session, looks the same from the store. `magus job prune` already refuses a
row that holds uncommitted work or a running check, so the path stays out of
reach until somebody ends the row.

## What to do

A worker cannot end another job. Tell the root or a person. They run the line
in the message: `--dry-run` lists what would end and ends nothing. If the
holder is gone, the same line without `--dry-run` ends it, and the path is free.

The window is `jobs.stale_after` in the workspace's own `magus.yaml`. When it
is 0, no holder is flagged.
