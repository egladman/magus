# MGS3056: model tiers from two declarations

`magus.TierCeiling` orders a child's tier against its parent's by rank, and a rank
means something only inside the `magus\modelTiers` declaration that gave it. Two
tiers from different declarations cannot be ordered, so the rule refuses them:

```text
[MGS3056] magus: spawn rule: model tiers "low" (Tier) and "low" (Tier) come from
  different declarations
```

## What to do

This happens when a program holds two workspaces' tiers side by side, or keeps a
tier past a reload of the magusfile that declared it. Parse both tiers from the
same `types.ModelTierSet`, the one the workspace declares now.
