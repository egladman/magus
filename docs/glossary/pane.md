# Pane

A split within a tab. Splitting divides the focused pane along its longer side,
so the same action tiles side-by-side on a desktop and stacks on a phone; a tab
with no split is a single pane. Drag the divider to re-weight the split.

## Example

Open the command bar and search for split; the focused pane divides along its longer side.

```text
mod+k
```
