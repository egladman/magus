# Workspace

The magus root directory that owns a set of projects and shared config; the unit
magus operates over.

## Elsewhere

npm, pnpm and Yarn workspaces, Cargo workspaces and Go's `go.work` each call a set of
packages that share one dependency resolution a workspace. A magus workspace is wider: it is
the root magus operates over, and it can hold several of those package-manager workspaces,
each inside a project.

## Example

`magus ls` lists every project the workspace discovered under its root.

```sh
magus ls
```
