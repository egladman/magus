# CI

An ordinary magusfile-defined target you compose yourself with `magus\needs`:
magus does not hardcode its stages. `Magus.RunCI` treats it specially only in
that it strips the `rw` charm, it is the anchor `magus affected ci` keys off,
and a selected scope with no project declaring it is a load error rather than
a silent no-op.

## Elsewhere

CI usually names the practice, or a hosted service that runs it (GitHub Actions, GitLab CI).
In magus it is an ordinary target named `ci`; a hosted runner calls `magus affected ci` like a
person does.

## Example

A `ci` target composes the stages; nothing about them is built in.

```buzz
export fun ci(ctx: magus\Context, args: [str]) > void {
    ctx.needs(generate, lint, test);
}
```
