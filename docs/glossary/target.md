# Target

A named operation (`build`, `test`, ...) you invoke with `magus run <target>`; it
may compose a spell's tool-native operations and depend on other targets.

## Elsewhere

In Make a target is a file or a phony rule name; in Bazel it is a labeled rule instance
(`//pkg:name`); a compiler's target is the platform it emits code for. A magus target is
always a named operation of one project, and `magus run <target> <project>` is how it runs.

## Example

```sh
magus run test libs/xdg
```
