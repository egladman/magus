# Agent

A model working through an agent host such as Claude Code, Codex, Cursor or
OpenCode: it reads, decides and calls tools inside the host's loop. magus
treats an agent as one more caller of its CLI, MCP tools and console, held to
the same guard and the same checks as a person. magus does not run, prompt or
route an agent; the host does.

## Elsewhere

Anthropic describes agents as systems where a model directs its own process and tool use,
as opposed to a workflow that follows fixed code paths. The Mastra TypeScript SDK and the
OpenAI Agents SDK each make an agent an object that bundles a model, instructions and tools
(`new Agent({ name, instructions, model, tools })` in Mastra). magus builds no agent object
and keeps no loop: an agent is whoever the host runs, and magus answers it.

## Example

`magus agent install` writes the skills, hooks and MCP wiring each host reads.

```sh
magus agent install
```
