# Snapshot

A point-in-time view of live state (the pool's occupancy or a tick of exported
metrics), as opposed to accumulated history.

## Elsewhere

A filesystem or VM snapshot freezes stored state so it can be restored; a snapshot test
compares output against a recorded file. A magus snapshot restores nothing: it is one reading
of live state.

## Example

```sh
magus status -o json
```
