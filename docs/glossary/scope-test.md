# Scope test

The question every proposed capability has to answer: does it read the model
magus already had to build, or does it make magus learn something new about the
world? Reads stay small; acquisitions are where a tool loses its shape.

## Example

`magus explain` reads the model magus already built; it is the shape of a capability that
passes.

```sh
magus explain internal/httpx
```
