# Backfill

The recent history the daemon replays to a dashboard on connect, so its charts
start populated instead of empty. It is served from a bounded ring buffer of the
last few hundred samples.

## Elsewhere

In data engineering a backfill recomputes a pipeline over a past date range (an Airflow
backfill). The magus backfill computes nothing: it replays samples the daemon already holds.

## Example

The console's dashboard receives the backfill when it connects to the daemon.

```sh
magus server start
```
