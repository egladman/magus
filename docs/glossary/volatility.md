# Volatility

A target that fails once and passes on rerun is **volatile**, as opposed to a
regression that started failing and stays failing. magus keeps per-target
pass/fail history and a Wilson-score volatility rate to tell them apart and
auto-retry the noise.

## Elsewhere

Most tools call such a test flaky. magus says volatile and keeps the rate per target, so a
retry is decided from history rather than from a retry count.

## Example

```sh
magus run --no-volatility-retry test .
```
