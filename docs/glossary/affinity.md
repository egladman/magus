# Affinity

An insight lens: projects that change together (temporal coupling). A pair that
co-changes without either declaring a dependency on the other is a candidate
architectural smell.

## Elsewhere

Code-forensics tools call this change coupling or temporal coupling. magus reads it from the
same history and checks it against the dependencies projects declare.

## Example

```buzz
magus\log.info(magus\insightMarkdown());
```
