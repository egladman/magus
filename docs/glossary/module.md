# Module

A magus stdlib namespace a magusfile imports for host capabilities: filesystem,
exec, vcs, and more.

## Elsewhere

A Go module is a versioned set of packages declared by `go.mod`; a JavaScript module is one
file with its imports and exports; a Python module is one `.py` file. A magus module is a
host namespace a Buzz script imports for a capability such as `fs`, `vcs` or `magus`.

## Example

```buzz
import "std";
import "fs";

fun main(args: [str]) > void !> any {
    foreach (p in fs\glob("*.md")) { std\print(p.value); }
}
```

`magus describe module fs` lists every method the module has.
