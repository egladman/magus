# Sandbox

The restricted filesystem and environment a target runs in, so builds stay
reproducible and side-effect-free.

## Elsewhere

An operating-system sandbox (macOS Seatbelt, Linux namespaces) or a browser sandbox confines a
whole process for security. Bazel's sandbox hides undeclared inputs from an action. The magus
sandbox is closest to Bazel's: it holds a target to the inputs and outputs it declared.

## Example

`magus describe target` shows what a target may read and write inside its sandbox.

```sh
magus describe target build docs
```
