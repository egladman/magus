# Service

A long-running or shared process magus manages across runs, distinct from a
one-shot target.

## Elsewhere

A systemd service is any unit the init system supervises; a Kubernetes Service is a stable
network endpoint in front of pods; a Compose service is one container definition. A magus
service is a process magus starts for targets and keeps across runs.

## Example

`magus broker status` lists the services the broker keeps warm.

```sh
magus broker status
```
