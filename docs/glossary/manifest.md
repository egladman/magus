# Manifest

The file that declares what a package is: its name, dependencies, entry points
and tool config (`go.mod`, `package.json`, `pyproject.toml`, `Cargo.toml`). How
the workspace builds, tests and lints the package belongs in the magusfile, not
in the manifest's scripts.

## Elsewhere

In container tooling a manifest is the OCI image manifest: the list of layer and config
descriptors that make up an image. A web app manifest describes an installable web app.
magus uses the word only for a package's own declaration file.

## Example

`magus describe project` shows which manifest a project's spell read.

```sh
magus describe project libs/xdg
```
