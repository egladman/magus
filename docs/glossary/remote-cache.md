# Remote cache

A CI-only backend that shares content-addressed artifacts across runners: a cold
machine replays a build another runner already did instead of rebuilding. Every
remote artifact must be signed by a trusted key.

## Elsewhere

Bazel, Gradle and Turborepo remote caches share artifacts between every machine, laptops
included. A magus remote cache is for CI runners only, and it refuses any artifact a trusted
key did not sign.

## Example

`magus config cache` shows which cache backends this workspace reads and writes.

```sh
magus config cache
```
