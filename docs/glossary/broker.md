# Broker

The per-user background process that holds this host's capacity: the machine
budget every run claims slots from, and the shared services runs keep warm. A
run starts it on demand; `broker: off` in `magus.yaml` runs without one.

## Elsewhere

A message broker (RabbitMQ, Kafka) routes messages between producers and consumers. The magus
broker passes no messages: it holds this host's build budget and the services runs share.

## Example

```sh
magus broker status
```
