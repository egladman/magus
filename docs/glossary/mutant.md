# Mutant

A touched function with one token swapped for another (`<` for `<=`, the `lt-le` swap in the Go spell), run in a
scratch copy through the spell's own test op. A test that fails kills the mutant; a
run that passes means it survived, so no test asserts on that token. An equivalent
mutant, one that cannot change behavior, is excepted with
`// magus:mutant op=<swap> reason=<why>` beside the site. A marker without a reason,
or one that matches no survivor, is itself a finding.

A cached run never decides a mutant: a replayed result ran no test. A mutant that
does not compile or load, after its unmutated run passed, is killed. A survivor is
refused only when its function has more survivors than the same function at base.

## Example

```go
// magus:mutant op=lt-le reason=the loop bound is never reached with equal operands
if a < b {
```
