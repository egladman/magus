# MAGUS.md

The committed routing index at a workspace root, regenerated from the knowledge
graph: it lists every node and points at the exact query for a given question,
so it is the entry point an agent reads first.

## Elsewhere

AGENTS.md and CLAUDE.md hold instructions a person wrote for an agent. MAGUS.md holds no
instructions: it is generated from the graph and only routes a question to the query that
answers it.

## Example

```sh
magus run index-generate docs
```
