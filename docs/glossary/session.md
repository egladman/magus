# Session

An agent host's conversation, by the id the host delivers to its hooks. magus
never mints one: a record with no session is unattributed, and the OS user it
carries says whose account ran it.

## Elsewhere

A web session is authenticated state behind a cookie. Agent hosts mean the conversation, which
is the sense magus takes; magus reads the host's id and never makes one up.

## Example

```sh
magus session --brief
```
