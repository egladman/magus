# Affected

The set of projects touched by a change; `magus affected <target>` runs a target
only over them.

## Elsewhere

Nx's `affected` and Turborepo's `--filter=[HEAD^1]` select projects from a git diff the same
way. magus reaches a project through the source globs it declares rather than through import
analysis, so a file outside every glob affects nothing.

## Example

```sh
magus affected ci
```
