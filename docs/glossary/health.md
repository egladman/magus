# Health

The at-a-glance daemon state derived from the pool: **healthy** when the pool is
reporting, **degraded** when it reports an error, **down** when there is no pool.
The dashboard color-codes each state.

## Elsewhere

A Kubernetes liveness or readiness probe answers one container's up-or-down. magus health has
three states, and degraded (the pool reports an error) is the one a probe would miss.

## Example

```sh
magus status --probe=readiness
```
