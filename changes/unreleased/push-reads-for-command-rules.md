### Added

- **A command rule reads what a push publishes and which of its files no run read.**
  `req.push` names the commit and checkout a push or `gh pr create` publishes, or why magus cannot.
  `magus\workspace(dir).unverified(revision)` lists the changed files no passing run read as committed.
  A run reads its target's declared inputs, or only the paths its command names.
