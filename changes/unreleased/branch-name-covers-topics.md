### Changed

- **A pushed branch name must cover what the branch holds.** The name must relate to
  half of the topics the branch adds: its changelog fragments, else its commit
  subjects. A miss denies from 3 topics up and advises on 1 or 2. Over 6 topics the
  name needs a theme word relating to most, or the denial says to split the branch.
  Each lists the topics the name misses.
