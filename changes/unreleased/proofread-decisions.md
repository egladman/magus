### Added

- **Proofread findings speak the guard's decisions and carry a `PRF` code.** Each finding names
  its rule, a code, `deny` or `advise`, and a link to `docs/reference/proofread/<rule>/`; a
  decisions table sets any rule `off`, `advise` or `deny`. `proofread rules` lists every
  rule, `proofread explain <rule>` prints one with its default decisions, and the docs render
  a page for each.
