### Changed

- **Written text is held to shape, tone and claim rules, each with a default decision.** The
  prose judge refuses reply voice, hedges, filler and the generated-writing tells by default,
  advises on judgment words, and leaves house style off until a repository's decisions table
  turns it on. The guard and `pr-description` run it on pull requests;
  `docs/conventions.md` lists the rules.
