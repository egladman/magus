### Added

- **Four codes name what degrades across magus builds.** MGS3047 is store records a
  newer magus wrote, skipped and kept. MGS3048 is a broker, server, pool parent or MCP
  server from another build. MGS3049 is a legacy store left beside its replacement.
  MGS3050 is a store line that is not a record at all, told apart from a newer one.
  Each page says what still works and the fix.
