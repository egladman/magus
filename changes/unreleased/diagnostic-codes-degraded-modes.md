### Added

- **Four codes name what degrades across magus builds.** MGS3047 is a job row,
  stored output or run history a newer magus wrote. MGS3048 is a broker, server,
  pool parent or MCP server from another build. MGS3049 is a legacy store left
  beside its replacement. MGS3050 is a store line that does not decode. Each
  page says what still works and the fix.
