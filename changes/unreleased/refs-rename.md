### Added

- **`magus refs <symbol> --rename <new>` renames a symbol at every verified site.**
  The sites are the ones `--occurrences` verified, column for column. A bare name
  that several workspace symbols carry is refused with their IDs; pass one. Before
  anything is written, every file is graded under the acting lease by the rules a
  host edit meets. A missing or stale index, an unverified site, a declared output
  or a guard deny refuses the whole rename. Every file is written or none is.
  `--check` prints the sites and writes nothing.
