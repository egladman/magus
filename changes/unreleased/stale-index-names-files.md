### Changed

- **A stale symbol index names the files that changed since it was built.**
  `magus status -o json` carries `changed` and `changed_count`, and the stale-index line
  under `refs`, `query` and `explain` and the guard's advice name up to five modified
  sources. `describe job` grades symbol goals against the built graph when none of those
  files is in the row's write paths.
